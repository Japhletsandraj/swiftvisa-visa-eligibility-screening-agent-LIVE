## Project Overview

SwiftVisa is an AI-based visa eligibility screening agent that helps applicants understand their visa eligibility requirements.

## Live Demo

🌐 **Try the Application:** [SwiftVisa Streamlit App](http://swiftvisa-ai-based-visa-eligibility-screening-agent-lcwg52tcgm.streamlit.app/)

> **Note:** The website will not return results when "Evaluate" is clicked if LM Studio is not running locally. This is because the application uses a local LLM for processing visa eligibility data.

## Requirements

- langchain
- langchain-community
- pypdf2
- sentence-transformers
- faiss-cpu
- streamlit
- python-dotenv

## Setup

1. Clone this repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Directory Structure

- `KB/` - Knowledge Base files
- `assets/` - Asset files
- `config/` - Configuration files
- `logs/` - Log files
- `models/` - Model files
- `scripts/` - Utility scripts
- `utils/` - Utility modules
- `vectorstore/` - Vector store data
